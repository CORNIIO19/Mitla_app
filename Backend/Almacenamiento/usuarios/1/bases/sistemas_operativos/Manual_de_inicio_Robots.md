Esta es una guía de instalación para diferentes sistemas operativos te permitira saber como iniciar con la programacion del robot makeblock e iniciar el IDE de programacion MBlock5

## Ingredientes

- Computadora
- Cable usb C 
- Navegador (De preferencia Chrome)


Para todos lo sistemas operativos necesitaremos al meno s3 cosas:
1. Un navegador como chrome, firefox, etc o desacrgar el ejecutable del IDE para windows o mac 
2. Descargar los drivers del programa makeblock
3. Tener acceso a los puertos seriales USB de tu computadora.
